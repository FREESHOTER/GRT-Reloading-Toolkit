The eight tools

All reached from one launcher window. Each writes its result into the load.

Chronograph Import

Athlon Rangecraft and Garmin Xero / ShotView exports — .xlsx, .xls, .csv, one file or a whole folder — into a GRT Measurement tab.

auto fps↔m/s · footer trimmed · one charge per file

Ladder / OCW Analyzer

Velocity flat-spot (Satterlee) + vertical-POI node (OCW / Audette) + a weighted best node, from chrono velocities and target groups.

→ OCW Analysis note + chart in the load

Seating-Depth Analyzer

Same engine on a seating / jump test — the group-size plateau plus the vertical-POI node.

→ Seating Depth Analysis note + chart

Barrel Calibration

Sweeps GRT for the simulated MV at every measured charge, compares to your chrono, and suggests a Ba tweak so the model matches your barrel.

Ba × (meas ÷ sim)² · scale-vs-shape verdict

Powder Temp Coefficients

Fits tcc / tch from strings of one charge shot cold, normal and hot.

Ba(T) ≈ Ba₂₁ · (MVT ÷ MV₂₁)²

Brass Prep

Case volume in grain H₂O → GRT's casevol; CBTO / case length / BBTO → gdepth; bushing & mandrel size for a target neck grip.

seating = BBTO − (CBTO − caselen)

Load Card / Label

Printable A6 recipe card or box labels with a QR of the full recipe. Component lots pull cost per round from the inventory.

Save PNG · Print · → Load Sheet note

Inventory & Load Journal

Component stock with lot tracking and cost per round, a range journal that deducts it, and a Firearms tab: round count and an MV-drift chart per barrel.

One thing to understand: the snapshot files

The GRT plugin interface can't edit the open load — so the toolkit writes beside it.

Every “Write to GRT load” reads your .grtload, adds its result — a result-field note, sometimes a gallery chart, sometimes a changed input (Ba, casevol, gdepth) — and saves a timestamped snapshot next to your file. Your original is never touched.

Every tool accumulates into the same snapshot family, so the newest one holds all your results. Only the three most recent are kept; older ones are pruned. A fresh filename each time is deliberate — GRT won't reload a path it already has open.

When you're done: open the newest snapshot in GRT, Save As under a real name, delete the rest. Ba, tcc/tch and casevol are always read from the pristine original, so a second calibration never compounds.

Install & reports

Drop-in folder. Restart GRT. One toolbar button.

  1. Copy the ReloadingToolkit folder into …\GRT-2021.2030…\plugins\.
  2. Restart GRT. A single Reloading Toolkit button appears on the toolbar and in the Plugin menu — it opens a launcher with one button per tool.
  3. In the launcher, click Install GRT report templates once. It adds five DokuWiki pages under doku\<lang>\report\ — open them from Results → + → Add report, on the snapshot file.
