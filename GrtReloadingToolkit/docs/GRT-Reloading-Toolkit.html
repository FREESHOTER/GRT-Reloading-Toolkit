The eighteen tools

Guided New Load

A checklist for one new load, front to back: brass prep and the load card before you leave, barrel calibration once you're back with a real measurement. Opens the real tool for each step; never reimplements one.

spans both phases · not a wizard that replaces the tools

Chronograph Import

Athlon Rangecraft and Garmin Xero / ShotView exports — .xlsx, .csv, one file or a whole folder — into a GRT Measurement tab.

auto fps↔m/s · footer trimmed · one charge per file

Chronograph Statistics

What GRT's own AVG/SD/ES line doesn't tell you: how far the true mean could plausibly sit from the one you measured, how many more shots would pin it down, whether a shot looks like it doesn't belong, and whether two strings really differ or that's just chrono noise.

90 / 95 / 99% CI · Chauvenet · n needed

Ladder / OCW Analyzer

Velocity flat-spot (Satterlee) + vertical-POI node (OCW / Audette) + a weighted best node, from chrono velocities and target groups.

→ OCW Analysis note + chart in the load

Seating-Depth Analyzer

Same engine on a seating / jump test — the group-size plateau plus the vertical-POI node.

→ Seating Depth Analysis note + chart

Barrel Calibration

Sweeps GRT for the simulated MV at every measured charge, compares to your chrono, and suggests a Ba tweak so the model matches your barrel.

Ba × (meas ÷ sim)² · scale-vs-shape verdict

Powder Temp Coefficients

Fits tcc / tch from strings of one charge shot cold, normal and hot.

Ba(T) ≈ Ba₂₁ · (MVT ÷ MV₂₁)²

Brass Prep

Case volume in grain H₂O → GRT's casevol; CBTO / case length / BBTO → gdepth; bushing & mandrel size for a target neck grip.

seating = BBTO − (CBTO − caselen)

Seating Force Estimate

Expected bullet-seating (press-fit) force, for a QC press's own “max pressure” threshold. Every length field carries its own mm/in dropdown, so you can mix units field by field.

baseline × prep factors · QC only

Load Card / Label

Printable A6 recipe card or box labels with a QR of the full recipe. Component lots pull cost per round from the inventory.

Save PNG · Print · → Load Sheet note

Load Journal

Every range session, typed in or read straight off the load open in GRT: charge, chrono string, group, environment, calibrated Ba/a0. Deducts inventory stock, and everything else here reads from it.

SQLite · %AppData%\GRTPlugins\

Find Best Ba

Searches your own logged calibrations for one caliber + powder + bullet combo, ranked by tightest group, closest velocity, or closest temperature to a target you set.

plots Ba, MV or group vs temperature

Inventory

Component stock with lot tracking and cost per round, a Firearms tab (round count and MV-drift chart per barrel), and a Brass Life tab tracking anneal and retirement per lot.

SQLite · %AppData%\GRTPlugins\

Load Leaderboard

Ranks every load you've ever logged on one 0‑10 score — a simple average of whichever of SD, ES, group, round count and cross-session consistency a load actually has. A load needs at least one real measurement to be ranked at all.

→ leaderboard note + report page

Distance Workflow

The same score, scoped to one distance: of the charges you shot today at this distance, which earns a test at the next one? No consistency term, and groups under three rounds are left out rather than scored low.

per-distance rank · → workflow note

Powder Compare

Of the powders you've actually calibrated in one caliber, which tends to work out for you — scored and ranked the same way as the Leaderboard, but grouped by powder instead of by exact recipe.

→ powder compare note + report page

Velocity Model

An empirical MV ≈ a + b·charge + c·temperature fit from your own logged sessions, independent of GRT's simulated model (no Ba/a0/tcc/tch) — a measured-data cross-check, plus a solver for the charge a target velocity needs.

needs charge AND temperature to both vary, independently

Advanced Diagnostics

Six diagnostics no other tool here does: fouling tracker, cold-bore effect, primer-lot sensitivity, neck-tension correlation, pressure-trend flattening, and session-over-session drift — none of them need a calibrated Ba to run.

→ diagnostics note + report page

One thing to understand: the snapshot files

The GRT plugin interface can't edit the open load — so the toolkit writes beside it.

Every “Write to GRT load” reads your .grtload, adds its result — a result-field note, sometimes a gallery chart, sometimes a changed input (Ba, casevol, gdepth) — and saves a timestamped snapshot next to your file. Your original is never touched.

Every tool accumulates into the same snapshot family, so the newest one holds all your results. Only the three most recent are kept; older ones are pruned. A fresh filename each time is deliberate — GRT won't reload a path it already has open.

When you're done: open the newest snapshot in GRT, Save As under a real name, delete the rest. Ba, tcc/tch and casevol are always read from the pristine original, so a second calibration never compounds.

Install & reports

Drop-in folder. Restart GRT. One toolbar button.

  1. Copy the ReloadingToolkit folder into …\GRT-2021.2030…\plugins\.
  2. Restart GRT. A single Reloading Toolkit button appears on the toolbar and in the Plugin menu — it opens a launcher with one button per tool.
  3. In the launcher, click Install GRT report templates once. It adds fourteen DokuWiki pages under doku\<lang>\report\ — open them from Results → + → Add report, on the snapshot file.
